# AI-Assisted Development Prompts

```text
1. Design a complete architecture for an Agile project management application similar to Jira, Asana, and Trello. Include frontend architecture, backend services, database design, authentication flow, task management, collaboration features, and deployment strategy.

2. Create a MongoDB database schema for a project management platform with users, projects, tasks, project members, comments, notifications, activity logs, attachments, labels, and relationships between collections.

3. Create a Figma design plan for an Agile project management application. Include authentication screens, dashboard layout, Kanban board, task details page, responsive design, and reusable UI components.

4. Suggest a scalable Next.js frontend folder structure for a project management application with authentication, pages, components, API services, state management, and reusable components.

5. Design a scalable Node.js and Express.js backend architecture for a project management application. Include routes, controllers, models, middleware, services, validation layer, and error handling structure.

6. Implement secure JWT authentication in Node.js and Express.js. Include user registration, login, password hashing using bcrypt, JWT token generation, and protected route middleware.

7. Create Express middleware to verify JWT tokens from Authorization headers, validate users, decode token information, and attach authenticated user details to request objects.

8. Create complete CRUD REST APIs using Express.js, MongoDB, and Mongoose for managing tasks. Include create, read, update, delete operations with proper validation and HTTP status codes.

9. Implement ownership-based authorization in Express APIs where users can only access, update, and delete resources created by them.

10. Design centralized error handling middleware for Express.js. Implement standardized JSON responses for validation errors, authentication failures, missing resources, and server errors.

11. Implement request payload validation using Zod or Joi in Express.js. Validate all incoming request bodies before database interaction and return meaningful validation messages.

12. Connect a React/Next.js frontend application with an Express backend using Axios. Implement API services, JWT authorization headers, loading states, and error handling.

13. Implement optimistic UI updates in React for task creation, deletion, and updates. Update the UI immediately while synchronizing data with backend APIs.

14. Implement Stripe Checkout integration in an Express backend. Create a secure payment session endpoint and explain the frontend payment workflow.

15. Design a secure server-side AI microservice architecture using Node.js and Express.js. The frontend should communicate only with backend AI endpoints, and AI API keys should remain protected using environment variables.

16. Create a POST /api/ai/suggest endpoint using Google Generative AI or OpenAI SDK. Accept project details, send requests securely to the AI model, and return sanitized JSON responses.

17. Implement express-rate-limit middleware to protect authentication and AI endpoints from brute-force attacks, excessive requests, and API abuse.

18. Review a Node.js Express production backend and suggest improvements including removing unnecessary console logs, improving security, optimizing middleware, and improving API performance.

19. Explain how to deploy a full-stack application with Next.js frontend, Node.js Express backend, and MongoDB Atlas database using Vercel and Render with environment variable configuration.

20. Generate professional GitHub README documentation for a full-stack project including project overview, architecture, features, technology stack, API documentation, installation steps, deployment details, security features, and future enhancements.
```
